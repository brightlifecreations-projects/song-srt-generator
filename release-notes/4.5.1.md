## SRT Generator 4.5.1 — always opens on the current screen

### Fixed

- **The old screen after updating, for good.** On some Macs the app said 4.5 but still showed the old top-tabs screen, because an older copy of the app (or its local server) was still running in the background and answered instead. Now, every time it opens, the app asks whatever is running on its port which version it is. If it's an older copy, the app stops it and starts its own; if something else is using the port, it moves to a free one. An old copy that was still open is closed for you rather than brought to the front.
- The screen also checks itself: if the page was built for a different version than the app's, it clears its cache and reloads once.
- **Fix automatically** in the Review panel sometimes left a "shorter than 0.3 s" warning on a cue it had just made exactly 0.3 s long. It now clears every warning.
- Opening the app while it's already open un-minimises its window again (broken in 4.5).

Windows: `SRT-Generator-4.5.1-win-lite.zip` (still untested on real Windows hardware).
