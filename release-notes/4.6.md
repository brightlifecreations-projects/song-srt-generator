## SRT Generator 4.6 — TikTok-style captions, word by word, and an SRT that matches the preview

### New

- **Captions that read well, on every page and in both modes.** One line per caption, at most 5 words and about 30 characters on vertical video (42 on horizontal), so nothing ever wraps. Lines are cut where you'd pause when reading: phrases stay together ("for her son", "in a size 4"), a subject stays with its verb, and a caption never ends on "the", "and", "to", "ka", "aur"… Change the word and character limits per page under *More options → Caption length*.
- **Line by line or Word by word.** A new two-button choice on every page, remembered per page. Word by word shows one word at a time, each timed to its own word. Switch a finished SRT either way in the Review panel: it's rebuilt from the same timings in about a second, without transcribing or aligning again.
- **Numbers as digits.** "twelve years" becomes "12 years", and the same goes for "Week 1", "7 a.m.", "70%", "size 4" and Hinglish counts ("do saal" → "2 saal"). Expressions like "not one inch", "one time" and "you two" stay in words; that list is editable on the Corrections page.
- **Speakers in a script.** A line starting with a name and a colon ("Sarah: …") starts a new caption, and the name is left out of it.
- **Only what's spoken.** Script lines that aren't in the audio are left out of the SRT and listed in a warning.
- **Captions start on the first spoken word** (no longer 0.2 s early) and end just after the last, never overlapping. Short captions are allowed, with an optional *Merge very short captions*.
- **Final AI check before output.** With an AI provider set up on the AI & API keys page (switch on by default), every SRT gets a last check for stray quotes, capitals, punctuation, numbers, misspellings and bad line cuts. The AI can only fix a word's spelling or move a cut between words, so no spoken word is added or dropped and the timing can't drift. Its changes are highlighted in the Review panel, with the original word and **Undo**; spelling fixes you keep are learnt in your corrections file (Source: AI). Without a provider, an offline cleanup does stray quotes, sentence case and numbers.

### Fixed

- **The downloaded SRT is exactly what the Review panel shows**, cue for cue. Before, a quick Download right after an edit (or while still typing one) could give the previous version, an emptied line disappeared from the file but not from the list, and the list rounded times to a tenth of a second. Times are now shown to the millisecond, and Download saves your latest edit first.
- SRT files are now always UTF-8 without a BOM, with Windows line endings (CRLF), which CapCut and Premiere read. Macs used to write Unix line endings.

### Windows

- **Tested on real Windows hardware for the first time** (Windows 11, AMD Ryzen, 16 GB): install, every page, both modes, audio and video, Hinglish Fast and Accurate, the Review panel, Corrections, AI & API keys (keys in Windows Credential Manager) and the Updates page.
- The voice-isolation engine is now picked automatically (GPU on Apple Silicon, CPU on Windows); a Windows checkout no longer needs config.py edited.
- The installer warns when the folder's path is long enough to hit Windows' path limit.
- Hindi file names work end to end (tested). As a precaution, ffmpeg's messages and the command line's output are now read in a way that can't fail on Hindi text.
- The Windows package versions are now pinned to the set that passed.

Windows: `SRT-Generator-4.6-win-lite.zip`.
